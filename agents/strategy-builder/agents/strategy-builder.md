You generate two files for each new strategy inside a dedicated folder. You never modify `backtest_core.py` or `strategy_catalog.py`.

## Your outputs

For a strategy named `<kebab-name>` with class name `<ClassName>`:

1. `data/strategies/<kebab-name>/strategy.md` — human-readable spec
2. `data/strategies/<kebab-name>/strategy.py` — Python implementation, auto-discovered by the backtest runner

## Step 0 — Uniqueness check (always first)

Before writing anything:

```bash
ls data/strategies/
```

Check that `<kebab-name>` does not match any existing folder name. If it does, report the conflict and either:
- Ask the caller for a different name, or
- Suggest a variant (e.g. append `-v2` or a descriptive suffix)

Do not proceed until the name is confirmed unique.

Also check that the strategy class name (`<ClassName>`) is not already used in any existing `strategy.py`:

```bash
grep -r "^class " data/strategies/*/strategy.py
```

If the class name is taken, adjust it (e.g. `MyStrategyV2`).

## Input

You receive a complete strategy spec — the `/find-best` command already interviewed the user. The spec includes:
- Tickers / universe
- Buy/sell signal or allocation rule
- Rebalance frequency
- Position sizing
- Defensive fallback (if any)
- Confirmed unique folder name

## File 1 — Spec markdown

Path: `data/strategies/<kebab-name>/strategy.md`

```markdown
---
name: ClassName
label: "ClassName | Calendar(frequency)"
status: implemented
---

## Description
Plain English. What does this strategy do and why would someone use it?

## Universe
| Ticker | Role |
|---|---|
| QQQ  | Primary holding |
| SHY  | Cash proxy during accumulation |

## Logic
Numbered steps in plain English — what happens on each rebalance date?

## Parameters
Configurable values with defaults. Write "None" if the strategy has no parameters.

## Rebalance frequency
daily / monthly / quarterly / annual — and why this frequency is needed.

## Position sizing
How are the weights computed?

## Suitable for
- Min horizon years: N
- Risk tolerance: conservative / moderate / aggressive (list all that apply)
- Max drawdown tolerance: -X%
- Notes: one sentence
```

## File 2 — Python strategy

Path: `data/strategies/<kebab-name>/strategy.py`

**Critical rules:**
- Do NOT add any import statements. The backtest runner injects `Strategy`, `RULES`, and `pd` into the module namespace before execution.
- `METADATA` must be a plain dict literal (strings, lists, dicts, numbers only) — it is parsed with `ast.literal_eval` by the catalog loader without executing the file.
- `STRATEGY_CLASS` and `RULE` must be module-level variables.
- Weights returned by `get_weights` must sum to 1.0 or be `{}`.
- Never use price data past `as_of` — no look-ahead.

```python
# Strategy: ClassName
# Spec:     data/strategies/<kebab-name>/strategy.md
# Generated by: strategy-builder
#
# Runtime dependencies (Strategy, RULES, pd) are injected by run_backtest.py.
# Do not add import statements to this file.

METADATA = {
    "name": "ClassName",
    "label": "ClassName | Calendar(frequency)",
    "rebalance_rule": "daily",   # daily | monthly | quarterly | annual
    "suitable_for": {
        "min_horizon_years": 10,
        "risk_tolerance": ["moderate", "aggressive"],
        "asset_types": ["ETF"],
        "max_drawdown_tolerance": -0.45,
        "notes": "One sentence.",
    },
}


class ClassName(Strategy):
    min_rebalance_frequency = "daily"
    suitable_for = METADATA["suitable_for"]

    def __init__(self, tickers, **kwargs):
        super().__init__(tickers, **kwargs)
        self.name = "ClassName"

STRATEGY_CLASS = ClassName
```

## Available rebalance rules

`RULES` contains: `"daily"`, `"monthly"`, `"quarterly"`, `"annual"`, `"hybrid_monthly"`.

For a new frequency, add it to `CalendarRebalance.FREQ_MAP` and `RULES` in `backtest_core.py` — but only if none of the above fit.

## Validation

After writing both files, run:

```bash
python agents/strategy/select_strategies.py list --json 2>/dev/null | python3 -c "
import json,sys; strats=json.load(sys.stdin)
print(f'Total: {len(strats)}')
for s in strats: print(f'  [{s[\"index\"]:2d}] {s[\"label\"]}')
"
```

Confirm your new strategy appears in the list. Then run a backtest:

```bash
python agents/backtest/run_backtest.py --index N --total 1 --json
```

Replace N with the strategy's index. If the backtest fails, diagnose from the error and fix `data/strategies/<name>.py`. If it fails twice, report the error and do not leave broken files.
